# Plan 1: Update WAHA Base & Re-apply Media Unlock Changes

## Goal
Update our fork of WAHA to the latest original upstream/core release (`2026.5.1`) and re-apply our custom overrides to enable sending images, files, and voice messages using the NOWEB and WEBJS engines.

## Proposed Steps
1. **Fetch & Merge Upstream Core**:
   - Fetch all updates from the official `upstream` remote.
   - Merge `upstream/core` into the local `core` branch.
   - Resolve conflicts in files like `src/core/engines/webjs/session.webjs.core.ts` or `src/core/engines/noweb/session.noweb.core.ts`.
2. **Re-add / Verify Source Code Changes**:
   - Re-introduce `src/core/utils/media.utils.ts` for file download/decoding.
   - Ensure `sendImage`, `sendFile`, and `sendVoice` methods are properly populated using the custom overrides in both `session.noweb.core.ts` and `session.webjs.core.ts`.
3. **Build & Update Dist Patch**:
   - Run `yarn install` to ensure package resolutions and dependencies are updated.
   - Run `yarn build` to verify there are no TypeScript or compilation errors.
   - Verify that the compiled JS files for our overrides (`dist/core/engines/noweb/session.noweb.core.js`, `dist/core/engines/webjs/session.webjs.core.js`, and `dist/core/utils/media.utils.js`) are updated and correct.
4. **Validation**:
   - Run tests using `yarn test` to make sure we didn't break anything.
   - Stage and commit the changes.
